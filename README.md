# DiskManagement
A simple C# GUI tool for managing disk online/offline states, designed to safely remove SATA drives on motherboards that do not support SATA Hot Plug, but do have drive trays with physical power switches.

A simple C# GUI tool for managing disk online/offline states, designed to safely remove SATA drives on motherboards that do not support SATA Hot Plug, but do have drive trays with physical power switches.

On AMD Ryzen–series motherboards, only ASUS BIOS allows enabling Hot Plug on individual SATA6G ports. Gigabyte motherboards only support Hot Plug as an all-or-nothing setting, and MSI motherboards appear to offer no such option at all.
